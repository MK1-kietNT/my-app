# WealthFlow — App Chi Tiêu, Tổng Tài Sản, AI & Lịch Cá Nhân

## 1. Chạy thử trên máy tính
```bash
npm install
npm run dev
```

## 2. Xuất file `.apk` cài lên Android (Miễn phí 100% qua GitHub)
1. Tạo 1 repository mới trên **GitHub** (để **Private** cho riêng bạn).
2. Push toàn bộ thư mục này lên GitHub (`main` branch).
3. Vào tab **Actions** trên GitHub → chọn workflow **Build Android APK** → đợi ~2 phút.
4. Bấm vào mục **Artifacts** → tải **`WealthFlow-Android-APK`** về, giải nén lấy file `app-debug.apk`.
5. Gửi file `.apk` sang điện thoại Android và bấm cài đặt là xong!

## 3. Bật AI thông minh (Miễn phí)
- Vào [Google AI Studio](https://aistudio.google.com) tạo 1 **Gemini API Key** miễn phí.
- Mở app → bấm icon **Cài đặt (⚙️)** → dán API Key vào.
- Không có key app vẫn chạy và phân tích nhanh offline bình thường.
